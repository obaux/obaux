## What was wrong, and what missed it

The first drag collapsed the drawer instead of opening it. Not the generator: `MapDrawer`'s handle ignored the
click a mouse drag ends with by checking `dragHeight === null`, which the pointer-up had already cleared, so a
drag up to full was followed by a tap that stepped it on to the dock. A finger fires no such click, so it was
never seen on a phone. Fixed with a ref (D-494); `e2e/trips-past.spec.ts` drags with the mouse and fails on the old
drawer. I wrote "D-494" in the code comment before claiming it (a guess from D-493 that happened to be right;
the rule is claim first, then write the number: the fourth time).
