# The weekly notes

Lena (languages & legal) and Wren (website) work in one batch a week, on Friday
(`docs/team.md`, "The weekly update"; Will, 10 October 2026). The merge desk keeps one file
per Friday, named for that Friday, and adds to it as it merges. On Friday it sends each of
them their part. The batch is the file and nothing else, unless Will adds to it.

Each line says what changed, where it shows, and what is wanted. No names, phone numbers or
email addresses: this repository is public.
