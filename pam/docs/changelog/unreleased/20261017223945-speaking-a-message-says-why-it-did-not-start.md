# Speaking a message says why it did not start

In a conversation, the microphone used to do nothing when speaking could not start: the browser refused the microphone, there was no connection, or the browser could not turn speech into words. Now a line above the message box says which, and what to do (type instead, allow the microphone, check the connection). "Listening" shows as soon as it starts. On a browser that cannot do speech at all, the microphone is still there, and a tap explains. (D-603)
