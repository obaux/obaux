# A program's services are kept, and members see them on any phone

A program lead can list the things the program does (GED classes, the computer room, a job
workshop) from the Program tab, and the list is saved: it is there on any phone, and members
see each service as a card on the program's page, with its own phone, address or hours where
they differ from the program's. Example programs still keep theirs on the screen only (D-313,
D-462).
