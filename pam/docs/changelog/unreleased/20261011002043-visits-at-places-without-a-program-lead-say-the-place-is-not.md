# Visits at places without a program lead say the place is not told

When you plan a visit at a place that no program leader runs on Pam (one Pam gathered from a public list), Pam now says plainly that the plan is only to help you, and that the place is not told you are coming. A trip there is "saved", not "booked". Places run by a program leader read as before. A program leader who has not added a program yet sees "Add your program" on Home and is asked to add it before opening Policies or services, instead of seeing example data (D-498).
