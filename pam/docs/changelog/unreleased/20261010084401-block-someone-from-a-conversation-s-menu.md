# Block someone from a conversation's menu

In a conversation, ⋯ now has Block this person. It asks first and says what a block does: neither of
you can send messages there or start a new one, what was said stays and can still be reported, and you
can unblock any time from the same menu. Afterwards the box for typing gives way to a note saying who
blocked, and the person who was blocked is told plainly (D-463).
