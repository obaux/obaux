# A planned trip is saved, and Pam reminds you the day before

When you plan a visit to a place in Pam's list, it is now saved: it is there on any phone you
sign in on, and moving it changes it everywhere. If you have turned text reminders on, Pam
texts you the day before, at the time you will be there, and the text moves with the visit
if you change it, or goes away if you cancel. If reminders are off, or you have never been
asked, Pam sends nothing (D-454). Example places still stay on the screen only.
