# The new tabs are the app

Signing in now shows the new bottom bar for your role — Explore, Saved, Trips, Messages and Profile for a
member; Home, Saved, Messages and Profile for a case manager; Home, Program, Messages and Profile for a
program lead — and each tab opens the redesigned screen. Your points and badge are on Profile. Old links
still work. A super admin switching the view now sees that view straight away (D-456).
