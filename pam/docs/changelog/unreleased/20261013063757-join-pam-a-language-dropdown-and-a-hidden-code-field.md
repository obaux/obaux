# Join Pam, a language dropdown and a hidden code field

- Opened from an invite, Sign in now says "Join Pam" and tells a newcomer what happens next: start with
  your phone number, Pam texts you a code.
- Joining asks for your language with one dropdown instead of seven chips.
- The invite code field is out of the way until you need it: "Did someone invite you via code?" and a
  link that opens it. It is already open if you came by an invite link or the code needs fixing.
- A case manager's sign-up says a person at Pam checks every request by hand and texts the answer, with no
  promise of how long it takes. An empty caseload says how to invite someone.
- An expired invite link offers to email a new one only once Pam really sends those emails; until then it
  points to the help desk.
