# Every list of languages starts with an English tag (EN, ES, PT-BR, ZH-CN, ZH-HK, RU, AR)

Every list of languages now starts each language with its short English tag: EN, ES, PT-BR,
ZH-CN, ZH-HK, RU, AR. The tag is the same in every language, so somebody who cannot read the
names can still tell which row is which before the name says it in its own language. It is on the
Language screen, the sign-in menu, the language choices when you join, and next to your language on
Profile. A screen reader still reads just the language's name, in that language's own voice (D-455).
