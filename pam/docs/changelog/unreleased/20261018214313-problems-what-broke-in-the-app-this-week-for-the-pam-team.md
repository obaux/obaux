# Problems: what broke in the app this week, for the Pam team

Super admins have a new list, Problems. It shows each action that failed in the last 7 days: what was being done, on which
screen, how often, and when it first and last happened, with the newest first. The bell opens it when something first goes wrong,
and it's also listed beside Waiting cities. It names no one and shows nothing anyone typed (D-616).
