# The help site says to write to us, not call, and has two new posts

The help site no longer mentions a phone number to call Pam. At the end of every post, and when a search finds
nothing, "Still stuck?" says to write to hello@joinpam.org and tell us what happened. Two new posts: "I can't sign in"
(who can join, how a case manager gets an invite, what to do when a code or an invite does not work) and "Your
safety" (911, 988, and how to tell Pam what happened). Search remembers what you typed when you come back from a
post, and the site is easier to use with a keyboard and a thumb: a visible outline on every link and button,
bigger tap targets, and a "skip to main content" link (D-522).
