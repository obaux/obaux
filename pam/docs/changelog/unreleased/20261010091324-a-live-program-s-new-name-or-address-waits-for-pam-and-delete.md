# A live program's new name or address waits for Pam; Delete and start over works

On a program that is live, a program lead can now change the name or address. Pam checks it
first: the Program tab says "Waiting for Pam" and shows what was asked, and members keep seeing
the program as it was until then. The lead can cancel the change. The description, phone number
and website still change at once. Deleting a program that was sent for checking and starting over
now really takes it back, and the lead lands on Add a program (D-447, D-462).
