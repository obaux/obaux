# A program can book a visit for a member who has written to it

A program lead can now book a visit for a member who has written to their program, and it is saved for real. The visit
shows on the member's Trips, and on Explore when it is their next one, marked "Booked for you by" the program. The bell
tells them, and they can move or cancel it like any visit. A case manager sees "Booked by" the program next to it on the
member's page. A program can only book for people who have written to it, and only a few times a day. (D-595)
