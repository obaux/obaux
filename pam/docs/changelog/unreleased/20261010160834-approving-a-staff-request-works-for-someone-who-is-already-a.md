# Approving a staff request works for someone who is already a member

If someone became a member while their request to lead a program was waiting, a super admin can now approve it: they become a program lead too, keep being a member, and can switch between the two. When a request cannot be approved the screen says why and what to do instead of "Call Pam". The request line now reads "Wants to add a program" (D-491).
