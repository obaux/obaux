# The app's reminder and alert lines say only what Pam sends today

The first screen no longer says Pam "reminds you before you go": it says Pam keeps your planned visits in one place.
Pam does not text a visit reminder yet, so the same promise is out of nine other places in all seven languages: the
program lead's first screen ("Members find your program and plan a visit."), the booked screen and the trip-added
screen (they say where the visit is, not that a reminder is coming), the Profile card (it offers the one text Pam
sends, when a place you saved closes or moves), the staff text-alert cards ("Coming soon: …"), the program form's
"We will let you know when yours is live" (it now says the Program tab shows where yours is), the terms line about a
new number, and the empty notifications screen (no longer says a booked visit shows up there). (D-474)
