# Trying an invite again after a lost answer gives the same invite

If the phone loses the answer while making an invite (the connection drops, or it takes longer than 15 seconds) and you tap
Create link again, you get the invite that was already made, with the same code. Pam no longer makes a second invite, and a
case manager or program lead no longer gets a second email. Change anything in the form first and it's a new invite.
(D-620)
