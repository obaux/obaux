# You can add a program from your Profile

Anyone with a Pam account can tap Add my program on their Profile, answer a few questions about it, and send it to Pam. Pam's team checks it by hand. While it waits, Profile says it is being checked; if it is not approved you can change it and ask again. When it is approved, you keep everything you have as a member and your program is yours to run (D-525).
