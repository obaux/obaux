# The workforce badge "Craftsman" is now "Maker"

The badge for finishing a workforce program is called "Maker" in English (Will, card a90), and has a name of its own in each
of the other six languages: Oficio, Ofício, 匠人 (both Chinese), Мастер and صانع. Its description does not change, and nobody
loses a badge they had: the key is an id, only the name on the screen is new.
