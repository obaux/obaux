# Message Pam: the Pam team's tools — saved replies, close and reopen, writing first, and Pam's hours

The Pam team now has more tools when answering people who write to Pam:

- A few saved replies, which fill the message box but are never sent on their own.
- Closing a conversation, and reopening it, from the conversation's ⋯.
- Writing first, as Pam, to anyone from Everyone, or to every lead of a program from its page.
- Setting when Pam is here, with the out-of-hours reply shown as people will get it.

All of this is behind the Message Pam switch (D-605, D-613).
