# The Pam team sees how many programs there are, and which are missing details

A super admin's Home now shows how many programs Pam lists, and how many have a phone, a website, an address and opening
hours. Parks & Rec places need only an address. A row under it, Missing information, opens a list of every place that lacks
something, with what it lacks. You can filter by what is missing and by the kind of place, and search by name or address. A
place opens its own page, and Back returns to the list as you left it. (D-623)
