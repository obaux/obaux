# A program can start a chat with you only if you signed up with it or have a visit planned there

The privacy page now says who can start a chat. A program can start a chat with you only if you are signed up with it or have a visit planned there. Otherwise only you can start one, and the program can answer. You can write to any program that is on Pam, even before you plan a visit. (D-541, D-543)
