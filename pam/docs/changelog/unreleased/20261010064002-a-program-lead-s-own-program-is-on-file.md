# A program lead's own program is on file, on any phone

When a program lead sends their program to Pam, it is now saved. Open Pam on another phone
and the Program tab shows it — waiting for Pam to check it, or live — instead of asking
them to add it again, and Home's getting-started cards follow. Once a program is live, its
description, phone number and website can be changed at once; its name, address and kind
of help are checked by Pam first, so they are shown but not editable (D-447).
