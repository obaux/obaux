# A super admin is asked before a decision and told after

- Approving or denying a staff request, and approving a program, now asks first ("Deny Andre? Pam will text Andre
  that the answer is no.") and says what happened after.
- Home shows how many programs are waiting to be checked, and the count no longer includes withdrawn ones.
- A program's phone, website and address open straight from the page that checks it.
- Back buttons go back the way you came.
- Small fixes for screen readers and text size on Everyone, Profile and the invites log.
