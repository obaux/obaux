# Sign up's city list holds only cities; the note is a line under it

On Sign up, the list of cities now holds only cities, each one a choice. "Pam is only in these cities for now." used to
sit at the foot of that list like a row you could tap, and tapping it did nothing. It is now a line of small print under
the field, seen before the list is even opened. No words changed. (Iris's interaction run-through, P5; D-369.)
