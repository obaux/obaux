# The privacy page says what a program sees before you plan a visit

Pam now says what a program can see of you before you plan a visit. If you write to a program, sign its rules, sign up with it or plan a visit there, it sees your first name, and what you write to it, and the day you signed its rules. The privacy page, the "What others can see" screens and the help site say the same thing, and the screen that lists what can be seen has a new card, "A program can see:". The line about the policies you sign has moved into that card, because your guide does not read them. (D-543)
