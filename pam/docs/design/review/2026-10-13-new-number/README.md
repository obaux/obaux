# A new phone number moves an account — pictures (13 October 2026)

390px, built app, Supabase stubbed, `claude/pam-new-number` (D-567). Light and dark.

- `01-signin-link`: "New number?" beside Privacy on Sign in.
- `02-new-number`: the new number proves itself with a code.
- `03-form`: the old account (old number, name, city, who at Pam knows them).
- `04-received`, `05-waiting`, `06-approved`, `07-denied`: what the person sees.
- `08-requests-list`: the super admin's Requests, a "New number" row.
- `09-review-top`, `10-review-tick`, `11-review-ticked`: typed beside the account, a mismatch marked, the tick before
  Approve.
- `12-moved`: after a yes, the sign-in moved.
- `13-protected`: a super admin's account, Deny only.
