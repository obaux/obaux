# SOP amendments from A26 on

Amendments up to A25 are in `docs/sop-amendments.md`. From A26 each is its own
file here, `A<number>-<words>.md`, headed `# A<number> — <title>`.

```
pnpm claim amendment "Short title"
```

Read `docs/sop-amendments.md` **and this folder** before trusting a rule you remember
from the SOP itself. Numbering works as for decisions (`docs/lanes.md`).
