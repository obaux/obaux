# Colour

Every colour is a token, and every token is a light/dark pair (`light-dark()`), so a screen works in
both modes without extra code. Use the token, never the hex. All values live in `tokens.css`.

## Rules

- **Accent green is for action and choice.** The filled primary button, the selected state, links
  and the accent ring of a picked card. Text on it uses `--color-on-accent`.
- **Light green is the quiet action.** Secondary buttons and a picked service card use
  `--color-accent-muted` with accent-coloured text.
- **Brand pink means "you are here" or "something new".** Only the selected tab and the unread dot.
  Never a button, never a heading.
- **Status colours come in pairs.** A strong colour for icons and text (`--color-warning`), its
  muted partner for the background (`--color-warning-muted`). Warning is "you still need to do
  this"; error is "this failed"; success is "done".
- **Grey cards are things to pick.** `--color-background-muted` sets a choice apart from content on
  white surfaces.
- **Contrast:** body text 4.5:1 or better on its background, in both modes. The pairs below are
  measured.
