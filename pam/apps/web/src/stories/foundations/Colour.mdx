# Colour

Every colour is a token, and every token is a light/dark pair (`light-dark()`), so a screen works in
both modes without extra code. Use the token, never the hex. All values live in the theme,
`@pam/ui/theme/pam.css` (and are mirrored for readers outside the code in `@pam/ui`'s `src/styles/tokens.css`,
generated: `pnpm --filter @pam/ui tokens`); the full list, read from the theme, is at the foot of this page.

## Rules

- **Accent green is for action and choice.** The filled primary button, the selected state, links
  and the accent ring of a picked card. Text on it uses `--color-on-accent`.
- **Light green is the quiet action.** Secondary buttons and a picked service card use
  `--color-accent-muted` with accent-coloured text.
- **Brand pink means "you are here" or "something new".** Only the selected tab and the unread dot.
  Never a button, never a heading.
- **Status colours come in pairs.** A strong colour for icons and text (`--color-warning`), its
  muted partner for the background (`--color-warning-muted`). Warning is "you still need to do
  this"; error is "this failed"; success is "done".
- **Grey cards are things to pick.** `--color-background-muted` sets a choice apart from content on
  white surfaces.
- **Contrast:** body text 4.5:1 or better on its background, in both modes. The pairs below are
  measured.

## Dark mode

In dark, **the page and cards are `#1B1B1B`, and `--color-background-muted` is `#262626`.** A card is told
apart from the page by the theme's hairline (`--shadow-low` and up draw a 1px inset edge in dark only), not by a
lighter fill, and that is on purpose. Muted is the grey ground of a thing set apart (a guide tile, the card behind
the next trip, the round back and send buttons, the avatar), so it has to be a different colour from the page: it
is the theme's lifted ground, the same value as `--color-background-surface`. It was `#1B1B1B` until 11 October
(D-504, Will: "yes go for it"), and those things had no shape in dark; see *Foundations › Dark muted ground* for
before and after. Text on `#262626`: primary 15.1:1, accent 10.7, status colours 9 or more (all AAA), secondary
5.65 (AA, as it was at 6.43 on the page).
