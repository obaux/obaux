# Typography

One family, **Figtree**, self-hosted from `@pam/ui` (`fonts.css`) — nothing loads from Google.
Fallback: the system UI font.

## Pam's sizes

Astryx's type roles are tuned for dense desktop apps; Pam sets its own sizes for phones and says so
in each component.

| Role | Size | Weight | Used for |
| --- | --- | --- | --- |
| Large title | 34px | 700 | The `h1` of a nested screen (`SubPage`) |
| Page title | 28px | 700 | Tab screens (`--pam-title-size`) |
| Section heading | 20–22px | 700 | "Pick a service", card headings |
| Body | 16px | 400 | Anything a member must read (`--pam-body-text-mobile`; was 18px until SOP A23) |
| Row label | 17–18px | 400–600 | `MenuList` rows, card names |
| Supporting | 15–17px | 400 | Second lines, hints, times |
| Button | 17px | 600 | `BigButton` |

Never go below 15px for something a member reads. Line height 1.4–1.5 for body text.
